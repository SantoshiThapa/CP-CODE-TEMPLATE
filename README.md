# Java Competitive Programming Template

## Features
- Fast I/O
- solve() structure
- Multiple test cases
- Bit manipulation helpers
- GCD, LCM, Modular Power
- lowerBound / upperBound
- Array utilities
- Pair class
- DSU
- Fenwick Tree

## Usage
Uncomment:
```java
t = fs.nextInt();
```
for multiple test cases.

Write your solution inside `solve()`.
